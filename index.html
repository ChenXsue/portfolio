Interactive Water – Real-Time Shallow Water Simulation (Niagara Fluids)

Built a physically-based shallow water system using Unreal Engine’s Niagara Grid2D solver. Refactored the default Niagara setup by replacing particle-based collision emitters with a Render Target–driven wave injection pipeline, allowing collisions to write directly into the Grid2D height/velocity fields. Implemented mesh-accurate interaction through Actor & Component collision tags, enabling stable player and object ripple deformation. Tuned simulation parameters including velocity dissipation, timestep multiplier, and collision velocity scaling to eliminate extreme wave artifacts and achieve smooth, responsive water behavior.

Unreal Engine | Niagara Grid2D | Shallow Water Solver | GPU Compute | Collision Wave Injection | Real-Time FX
